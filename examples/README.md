# Examples

Run `npm run build` first, then serve the repository root (for example with `npx serve .`) and open:

- [`script-tag.html`](script-tag.html): the UMD build as a classic `<script>`, using `window.Forcify`
- [`esm.html`](esm.html): the ES module build with `import`
- [`amd.html`](amd.html): the UMD build loaded by an AMD loader

The [website](https://huxpro.github.io/forcify) has a live demo for every option, event and API.
