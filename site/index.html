Getting started

Forcify gives you a single force value from 0 to 1 on any hardware. On 3D Touch iPhones, Force Touch trackpads and pressure pens it is real pressure. Everywhere else, a long press emulates it.

on('force', handler)

Create an instance on an element and listen to force. That is the whole API most apps need.

How it works

Each press is served by the best source available. Every event reports which source it came from.

sourceHardwareRead from
'touch3d'iPhone 6s – XS 3D TouchTouch.force, touchforcechange
'forcetouch'Mac Force Touch trackpadsMouseEvent.webkitForce, webkitmouseforce*
'pen'Apple Pencil, Surface Pen, S Pen, Wacom…PointerEvent.pressure, tilt, twist, altitude/azimuth
'longpress'Everything elseEmulated: after LONG_PRESS_DELAY, ramps 0 → 1 over LONG_PRESS_DURATION

Events

A press emits forcestart, then force for every change, with peek and pop as it crosses the thresholds, and finally forceend. A pen hovering above the element emits hover.

Event object

Every force event carries the value, where it came from, where the pointer is, how a pen is held, and how the press has gone so far. Try it with a pen to see the tilt fields change.

      hover

        Instance

        An instance owns one element. Every method except destroy() returns the instance, so calls chain.

        new Forcify(elementOrSelector, options?)

        The constructor takes an element or a CSS selector. Options override Forcify.defaults for this instance only. e.target is always the instance's element.

        #selector-pad

        once(type, handler)

        Listens a single time, then removes itself. Pop twice and only the first one is logged. Reset to try again.

          off(type?, handler?)

          Removes one handler, every handler of a type, or every handler. Untick the box and the output stops updating, even though the pad still fills through CSS.

          Options

          Pass options to the constructor, or change defaults for every new instance with Forcify.config(). Each demo below builds a new instance whenever you change a control.

          LONG_PRESS_DELAY: 200

          How long, in milliseconds, a press must be held before the emulated force begins. Anything shorter is a tap.

          Press & hold
          200ms

            LONG_PRESS_DURATION: 1000

            How long, in milliseconds, the emulated force takes to ramp from 0 to 1.

            Press & hold
            1000ms

            LONG_PRESS_TOLERANCE: 10

            How many pixels the pointer may move before a pending long press is cancelled, so scrolling and swiping never trigger fake force. Press and drag straight away: past the tolerance, nothing happens.

            Press, then drag
            10px

              LONG_PRESS_EASING: t => t

              Shapes the emulated ramp. The function receives linear progress from 0 to 1 and returns a force.

              Press & hold

              FALLBACK_TO_LONGPRESS: true

              Emulate force with a long press on devices with no pressure hardware. Turn it off to react only to real pressure: on a phone or laptop without it, the right pad stays empty.

              true
              false

              SHIM_WEIRD_BROWSER: true

              Many Android devices report finger area as Touch.force, and old Chrome reported a constant 1. Forcify ignores those values by default. On Android, press both pads: the right one reacts to how much of your finger touches the screen.

              true
              false

                POINTER_TYPES: ['mouse', 'touch', 'pen']

                Which pointers may press. For example, ['pen'] makes a surface that only a stylus can press, so a resting palm is ignored.

                Press with an allowed pointer

                  PEEK_THRESHOLD: 0.3 · POP_THRESHOLD: 0.6

                  The force at which peek and pop fire. A macOS force click always pops. With the default long-press ramp, peek lands at 500 ms, matching iOS Haptic Touch.

                    HAPTICS: true

                    3D Touch made you feel every peek and pop. Forcify plays a light haptic on peek and a medium one on pop, where the platform allows. Android uses navigator.vibrate. On iOS 18 and later, Forcify borrows the haptic Safari plays when a switch toggles. Both are best-effort.

                    true
                    false

                    This device:

                    PREVENT_CLICK: true

                    When a press reaches peek, the click that follows on release is swallowed, so a hard press doesn't also activate the button. Tap both buttons, then long-press both, and compare the counts.

                    DISABLE_NATIVE_GESTURES: true

                    A long press normally belongs to the platform: the iOS callout and link preview, text selection, dragging, the Android context menu, and Look Up on a Mac. Forcify switches these off on its element. Long-press the right-hand link on a phone to see what it prevents.

                    true
                    (a link)                     false
                    (a link)

                    CSS_VARIABLE: '--force'

                    Forcify writes the force to a CSS custom property on the element, so styles can follow the press with no handler at all. Every pad on this page is filled this way. Use a different name, or false to turn it off.

                    STATE_ATTRIBUTE: 'data-force-state'

                    During a press the element carries data-force-state="pressing", then "peek", then "pop". The attribute is removed when the press ends.
